# План 0.9 — врата телепортации (договорились 12.11)

## Точка дома
- Ставится в квартире (рядом с витриной и сундуком).
- Ур. 1 — этаж 1; каждый уровень +1 этаж. Улучшение — ресурсы нового этажа + Искры, только если этаж открыт по сюжету.

## Врата по миру
- Найти (подойти) → в меню серые «сломаны» → починить ресурсами локации (+ иногда редкое «ядро врат» с элиток/тайников).
- Этаж 1, юг: Пристань Тракта, Лагерь, Руины, Арена, у логова Громилы.
- Этаж 1, север: Северная пристань, Аванпост, Озеро, у Склепа.
- Этаж 2: Станция, Площадь Неона, Рынок, Парк, Альтаир, люк у Гоши, у клуба Дона.
- Перенос БЕСПЛАТНЫЙ. 3 с на месте, КД ~30 с; нельзя в бою, из темницы, во время звонка Элеоноры.
- Модель: постамент с рунами + парящий вращающийся кристалл; сломанные — треснувшие, кристалл лежит; цвет по этажу (иней/пепел/неон). Вспышка и кольцо частиц при переносе.

## Меню врат
- Вкладки Мир → Этаж, список точек: название, описание, статус, что нужно для починки. Место под картинку (скриншоты позже).

## Такси
- Главное: «Домой» из любого места за небольшую плату.
- Карту такси пока оставить как есть; механику с картой придумаем потом.

## Курьер «Шпиль.Еды» — куда везти
- К двери квартиры 40 ✦ (~90 с) / к починенным вратам 70 ✦ (~2 мин, ждёт 3 мин) / ко мне 120 ✦ (по расстоянию). Экспресс — поверх любого. Между этажами дороже.
- «Ко мне»: не идёт в логово босса, арену, глубь канализации, PvP-зону — ждёт у входа/ближайших врат. В бою ждёт в стороне. В темницу Кармиллы — шуточный отказ.
